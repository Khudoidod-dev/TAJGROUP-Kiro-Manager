## 📥 Installation

### Step 1 — Get a License Key (Free)

> A license key is required. It's free — just subscribe!

1. Subscribe to our [Channel](https://t.me/tajgroup_official) and join our [Group](https://t.me/tajgroup_chat)
2. Open bot [@tajgroupkirobot](https://t.me/tajgroupkirobot)
3. Press **"🔑 Get Key"**
4. Copy the key

### Step 2 — Install

1. [Download the installer](https://github.com/Khudoidod-dev/TAJGROUP-Kiro-Manager/releases/latest)
2. Run `TAJGROUP-Kiro-Manager-1.0.0-setup.exe`
3. Follow the installation wizard

### Step 3 — Activate

1. Launch the application
2. Enter the key from the bot
3. Done! ✨
