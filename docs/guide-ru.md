## 🔐 1. Регистрация аккаунтов

> Каждый аккаунт Kiro даёт **50 запросов в месяц** бесплатно. Чем больше аккаунтов — тем больше лимит.

<br>

### 📌 Способ 1: Вручную через браузер

Самый простой способ для начала:

| Шаг | Действие |
|:---:|----------|
| 1 | Зайди на **[kiro.dev](https://kiro.dev)** |
| 2 | Нажми **"Builder ID"** |
| 3 | Введи email (Outlook, Gmail — любой) |
| 4 | Подтверди код с почты |
| 5 | Создай пароль |
| 6 | ✅ Аккаунт создан |

После входа в Kiro IDE → TAJGROUP Manager автоматически подхватит токен.

<br>

### 📌 Способ 2: Через приложение (автоматически)

Для массовой регистрации:

1. Открой **"Регистрация"** в меню слева
2. Выбери режим:

| Режим | Описание | Что нужно |
|-------|----------|-----------|
| **Вручную** | Один аккаунт за раз | Email + пароль |
| **Outlook** | Массовая через Outlook | Готовые Outlook аккаунты |
| **Свой домен** | Через свой домен с catch-all | Домен + TempMail.Plus |
| **Смешанный** | Комбинация источников | Настроенные источники |
| **TempMail** | Через временные почты | Ничего не нужно |

3. Нажми **"Начать регистрацию"**
4. Приложение автоматически:
   - ✅ Регистрирует Builder ID
   - ✅ Получает токен
   - ✅ Добавляет аккаунт в список

<br>

### 📌 Способ 3: TempMail (самый простой)

> Не нужны реальные email — приложение создаёт временные почты само.

1. Выбери режим **"Смешанный"** или **"TempMail"**
2. Укажи количество аккаунтов
3. Нажми **"Начать"**
4. Готово — аккаунты появятся в списке

<br>

### 📌 Формат Outlook аккаунтов (для режима Outlook)

```
email@outlook.com----пароль----clientId----refreshToken
```

| Поле | Откуда взять |
|------|-------------|
| `email` | Твой Outlook адрес |
| `пароль` | Пароль от Outlook |
| `clientId` | `b49c45fb-4ece-4bff-9ae3-94d8e39e8f41` (фиксированный) |
| `refreshToken` | Появляется после первого входа в Kiro |

## 👥 2. Управление аккаунтами

### Переключение аккаунта

1. Открой **"Аккаунты"**
2. Нажми ⚡ на нужном аккаунте
3. Kiro IDE мгновенно переключится

### Статусы аккаунтов

| Статус | Значение |
|--------|----------|
| 🟢 **Активен** | Работает, токен действителен |
| 🟡 **Обновляется** | Токен обновляется автоматически |
| 🔴 **Ошибка** | Проблема с токеном или бан |
| ⏰ **Истекает** | Скоро закончится лимит |

### Автопереключение

Когда лимит одного аккаунта заканчивается — приложение **автоматически** переключает на следующий.

**Настройка:**
- API Прокси → **"Мультиаккаунт"** → включить
- Стратегия:
  - **Round-Robin** — каждый запрос через другой аккаунт (рекомендуется)
  - **Sticky** — один аккаунт пока не кончится лимит

### Группы и теги

Организуй аккаунты для удобства:
- **Группы** — разделяй по назначению (работа, тест, резерв)
- **Теги** — помечай (VIP, бесплатный, новый)

## 🌐 3. API Прокси сервер

> Превращает твои аккаунты Kiro в API-сервер, совместимый с OpenAI и Claude.

### Что это даёт

- 🔄 **Ротация** — автоматическое переключение между аккаунтами
- 🔑 **Единый API** — один адрес для всех клиентов
- 📊 **Статистика** — сколько запросов, какой аккаунт, расход
- 🛡 **Безопасность** — API ключи, IP фильтр, TLS

### Как включить

1. Открой **"API Прокси"** в меню
2. Нажми **"Запустить"** (зелёная кнопка)
3. Адрес появится: `http://127.0.0.1:5580`

## 🔌 4. Настройка прокси

> Прокси нужны чтобы каждый аккаунт выходил в интернет с разного IP — это защита от блокировки.

### Зачем прокси

| Без прокси | С прокси |
|-----------|----------|
| Все аккаунты с 1 IP | Каждый аккаунт — свой IP |
| Kiro видит что 40 акков с одного IP | Kiro видит 40 разных "пользователей" |
| Риск бана | Безопасно |

### Где взять бесплатные прокси

| Сервис | Бесплатно | Тип |
|--------|:---------:|-----|
| **[Webshare.io](https://webshare.io)** | 10 прокси навсегда | SOCKS5 / HTTP |
| **[ProxyScrape](https://proxyscrape.com)** | Список публичных | Ненадёжные |
| **[Geonode](https://geonode.com)** | Ограниченно | HTTP |

### Настройка Webshare (пошагово)

**Шаг 1:** Зарегистрируйся на [webshare.io](https://webshare.io) (бесплатно)

**Шаг 2:** Proxy Settings → **IP Authorizations** → нажми **"add my IP"**

> ⚠️ **Без этого шага прокси не будут работать!**

**Шаг 3:** Proxy List → **Download** → скопируй содержимое

**Шаг 4:** Конвертируй формат:

```
Webshare формат:     ip:port:user:pass
Нужный формат:       socks5://user:pass@ip:port
```

**Пример:**
```
Было:    31.59.20.176:6754:yopuzxdh:59981u8ojcly
Стало:   socks5://yopuzxdh:59981u8ojcly@31.59.20.176:6754
```

**Шаг 5:** В приложении → **"Пул прокси"** → **Bulk** → вставь все строки → **Добавить**

**Шаг 6:** Нажми **"Тест всех"** — должны стать 🟢 Живые

**Шаг 7:** Нажми **"Авто-привязка непривязанных"** — распределит аккаунты по прокси

### Типы прокси

| Тип | Формат | Когда использовать |
|-----|--------|-------------------|
| **SOCKS5** | `socks5://user:pass@ip:port` | Рекомендуется (работает через VPN) |
| **HTTP** | `http://user:pass@ip:port` | Стандартный |
| **Без авторизации** | `socks5://ip:port` | Если пароль не нужен |

### Привязка аккаунтов к прокси

- **"Аккаунтов на прокси: 5"** — по 5 аккаунтов на 1 IP
- **"Авто-привязка"** — автоматически распределит
- Или вручную: Аккаунт → Редактировать → Выбрать прокси

> 💡 С 10 прокси и 5 акков/прокси = 50 аккаунтов через 10 разных IP

## 🔑 5. Machine ID (защита от банов)

> Machine ID — уникальный идентификатор устройства. Kiro использует его чтобы связывать аккаунты.

### Почему это важно

Если у тебя 40 аккаунтов с одним Machine ID → Kiro поймёт что это один человек → бан всех аккаунтов.

### Как настроить

1. Открой **"Machine ID"** в меню
2. Нажми **"Сгенерировать и применить"**
3. Каждому аккаунту назначь уникальный ID

### Режимы

| Режим | Описание |
|-------|----------|
| **Авто** | При переключении аккаунта — Machine ID меняется автоматически |
| **Привязка** | Каждому аккаунту свой фиксированный ID |
| **Ручной** | Вводишь свой UUID |

> ⚠️ Всегда используй уникальный Machine ID для каждого аккаунта!

## 💡 6. Полезные советы

### Минимальная настройка для работы

```
5-10 аккаунтов + Round-Robin = комфортная работа без rate-limit
```

### Оптимальная настройка

```
30-50 аккаунтов + 10 прокси + Machine ID = безлимит без банов
```

### Рекомендации

| Совет | Почему |
|-------|--------|
| Минимум 5 аккаунтов | 1 аккаунт = 50 запросов, 5 = 250 |
| Round-Robin стратегия | Равномерная нагрузка |
| SOCKS5 прокси | Работают через VPN из России |
| Уникальный Machine ID | Защита от массового бана |
| Автообновление токенов | Включено по умолчанию |
| Не больше 5 акков на 1 IP | Иначе подозрительно |

### Если "Too many requests"

1. Проверь что **мультиаккаунт включён** (API Прокси)
2. Добавь больше аккаунтов (минимум 5)
3. Подключи прокси (разные IP)
4. Подожди 1-2 минуты — rate limit сбрасывается

### Если аккаунт заблокирован

1. Смени Machine ID
2. Подключи другой прокси
3. Подожди 24 часа
4. Или создай новый аккаунт
