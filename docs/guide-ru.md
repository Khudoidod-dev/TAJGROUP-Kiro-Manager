# TAJGROUP Kiro Manager — Руководство

## 1. Регистрация аккаунтов Kiro

### Способ 1: Вручную (через браузер)

1. Зайди на **kiro.dev**
2. Нажми **"Builder ID"**
3. Введи email (Outlook, Gmail — любой)
4. Подтверди код с почты
5. Создай пароль
6. Готово — аккаунт Kiro создан

После входа в Kiro IDE — TAJGROUP Manager автоматически подхватит токен.

### Способ 2: Через приложение (Регистрация)

1. Открой **"Регистрация"** в меню слева
2. Выбери режим:
   - **Вручную** — вводишь email + пароль, приложение само регистрирует
   - **Outlook** — массовая регистрация через Outlook аккаунты
   - **Свой домен** — свой домен с catch-all почтой
   - **Смешанный** — комбинация нескольких источников

3. Нажми **"Начать регистрацию"**
4. Приложение автоматически:
   - Регистрирует Builder ID
   - Получает токен
   - Добавляет аккаунт в список

### Формат Outlook аккаунтов

```
email@outlook.com----пароль----clientId----refreshToken
```

- **email** — твой Outlook
- **пароль** — пароль от Outlook
- **clientId** — `b49c45fb-4ece-4bff-9ae3-94d8e39e8f41` (фиксированный для Kiro)
- **refreshToken** — получается после первого входа в Kiro

### Способ 3: TempMail (временная почта)

1. Режим **"Смешанный"** или **"TempMail"**
2. Приложение само создаёт временные почты
3. Регистрирует через них аккаунты
4. Не нужны реальные email

## 2. Использование аккаунтов

### Переключение аккаунта

1. Открой **"Аккаунты"**
2. Нажми иконку ⚡ на нужном аккаунте
3. Kiro IDE переключится на этот аккаунт

### Автопереключение

В настройках API Прокси:
- Включи **"Мультиаккаунт"**
- Стратегия **"Round-Robin"** — каждый запрос через другой аккаунт
- Или **"Sticky"** — один аккаунт пока не кончится лимит

### Machine ID (защита от банов)

1. Открой **"Machine ID"**
2. Нажми **"Сгенерировать и применить"**
3. Каждый аккаунт получит уникальный идентификатор устройства
4. Kiro не сможет связать аккаунты между собой

## 3. API Прокси (использование через клиенты)

### Что это

API Прокси превращает твои аккаунты в API-сервер совместимый с:
- **OpenAI** (ChatGPT формат)
- **Claude** (Anthropic формат)

Любой клиент который поддерживает OpenAI API — будет работать.

### Как включить

1. Открой **"API Прокси"**
2. Нажми **"Запустить"**
3. Адрес: `http://127.0.0.1:5580`

### Подключение к клиентам

**Cursor / Windsurf / Continue:**
- API URL: `http://127.0.0.1:5580/v1`
- API Key: (оставь пустым или введи свой из настроек)
- Model: `claude-sonnet-4.5` или любая

**Claude Code:**
- `ANTHROPIC_BASE_URL=http://127.0.0.1:5580`

**OpenAI совместимые:**
- Base URL: `http://127.0.0.1:5580/v1`

## 4. Прокси (для обхода блокировок)

### Зачем нужны

- Обход rate-limit (Too many requests)
- Каждый аккаунт через свой IP
- Защита от блокировки по IP

### Где взять

1. **Webshare.io** — 10 бесплатных прокси навсегда
2. **Proxy-cheap.com** — от $1
3. **Proxies.fo** — резидентские

### Настройка Webshare

1. Зарегистрируйся на webshare.io
2. Proxy List → Download
3. Формат из Webshare: `ip:port:user:pass`
4. Конвертируй в: `socks5://user:pass@ip:port`

**Важно:** на странице Proxy Settings → IP Authorizations → добавь свой IP!

### Добавление в приложение

1. Открой **"Пул прокси"**
2. Нажми **"Bulk"**
3. Вставь прокси (по одному на строку):

```
socks5://user:pass@ip:port
socks5://user:pass@ip:port
```

4. Нажми **"Добавить"**
5. Нажми **"Тест всех"** — проверит работоспособность
6. Нажми **"Авто-привязка"** — распределит аккаунты по прокси

### Формат прокси

| Тип | Формат |
|-----|--------|
| HTTP | `http://user:pass@ip:port` |
| SOCKS5 | `socks5://user:pass@ip:port` |
| Без пароля | `http://ip:port` |

### Привязка к аккаунтам

- **"Аккаунтов на прокси: 5"** — по 5 аккаунтов на 1 прокси
- Нажми **"Авто-привязка непривязанных"**
- Или вручную: в аккаунте → редактировать → выбрать прокси

---

## 5. Советы

- **Минимум 5-10 аккаунтов** для комфортной работы без rate-limit
- **Round-Robin** — лучшая стратегия для распределения нагрузки
- **SOCKS5** прокси работают лучше HTTP из России (через VPN)
- **Machine ID** — обязательно менять для каждого аккаунта
- **Автообновление токенов** — включено по умолчанию, токены обновляются автоматически
